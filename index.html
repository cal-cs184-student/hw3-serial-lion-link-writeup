Part 1: Ray Generation and Scene Intersection

For ray generation, we first convert the hFov and vFov variables to radians, then we convert to the image coordinates to sensor coordinates using the expressions given in the spec. We also need to make sure the previous origin at the bottom left is now the center in the camera space. Then we set the direction to point down the Z axis and transform from camera space to world space and normalize the ray. In the triangle intersection section, we used the Moller Trumbore algorithm from lecture. Since we have three unknowns (t and two of the barycentric coordinate weights for the triangle) and 3 axes, we can make a system of linear equations. The algorithm uses Cramer's Rule to find the solutions, but we also used the lecture slide as a guide to set the right components.

Part 2: Bounding Volume Hierarchy

For the BVH construction, we first reuse the root bounding box construction from the starter code while also keeping track of the number of nodes we encounter. Then, we add the base case where we compare the number of nodes to the maximum count for leaves; for simplicity, we first chose the split point to be the average centroid along the x-axis.
